## 可复现测试

在公开仓库根目录安装`requirements.txt`后运行：

```powershell
python -m unittest discover -s server/tests -p "test_*.py" -q
python -m unittest discover -s client-adapter/tests -p "test_*.py" -q
python -m unittest discover -s tools/resource-recovery -p "test_*.py" -q
```

Windows自建i686模型需要VS2022/MSVC14.36（源码中固定该工具链）：

```powershell
powershell -NoProfile -File tools/client-lab/native-cloud-ticket/Build.ps1 -OutputDirectory C:\Temp\kk-native-new-build
python tools/client-lab/Test-NativeEncryptedTransport.py --model C:\Temp\kk-native-new-build\contract.exe
powershell -NoProfile -File tools/client-lab/Test-NativeCloudHandoff.ps1 -BuildDirectory C:\Temp\kk-native-new-build
powershell -NoProfile -File tools/client-lab/Test-KkNativeEgress.ps1
powershell -NoProfile -File tools/client-lab/Test-KkLocalAccountWindow.ps1
```

构建目录必须不存在，避免覆盖上一次结果。上述测试只运行自建模型、临时SQLite和回环套接字，不加载原SDK、不启动游戏，也不应用防火墙规则。

## 新路径不是即插即用客户端包

`server/configs/native.example.json`只包含路径/端口示例，没有TLS证书或密钥。
`tools/client-lab/native-cloud-ticket/launcher.example.json`同样不包含密码；填写它不等于已具备完整客户端初始化条件。

真实游戏还依赖合法客户端副本、版本匹配的SDK、编译后的适配器/注入器，以及本地项目已有的专用初始化适配。该实验初始化器和VM环境没有随本次公开快照打包。新登录窗口的旧分支也依赖本地实验入口，因此公开窗口源码用于集成和测试，不宣称独立部署后能直接进入游戏。

源码中的C:\KK-Lab和工具安装路径是环境约束/示例，不是已安装资源。不要通过假就绪文件或关闭证书校验补齐缺件。
